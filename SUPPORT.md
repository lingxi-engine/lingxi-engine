# Support

## Where to ask what

### Installation or setup problems

Open an issue with the **Installation problem** template and include:

- operating system
- Node/Python versions
- provider configuration path (for example Ollama vs cloud API)
- exact command output or screenshots with secrets removed

### Bugs

Open an issue with the **Bug report** template and include a minimal reproduction, expected behavior, actual behavior, and logs.

### Feature requests

Open an issue with the **Feature request** template and describe the problem you want to solve before proposing a design.

### Documentation problems

Open an issue with the **Documentation problem** template or send a pull request directly for small fixes.

### Security issues

Do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).

## Support boundaries

- This repository is a self-hosted developer preview.
- Maintainers may not be able to provide immediate support for custom deployments, third-party channels, or experimental features.
- There is no public support SLA and no promised hosted service in this repository.
