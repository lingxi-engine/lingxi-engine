## 技术参数

- **曲式**: 前奏(4) → 主歌A(8) → 主歌B(8) → 副歌1(8) → 副歌2(8) → 间奏(4) → 副歌3(8) → 尾奏(4) = 52 小节
- **BPM**: 96，4/4 拍，C 大调
- **和声**: I-V-vi-IV 进行（C-G-Am-F），副歌段梯度推进
- **时长**: 130.0 秒

## 声部（8 轨）

1. **鼓组** Kick/Snare/HiHat/Clap，四段力度分层（主歌 0.55 / 副歌 0.95 / 间奏 0.5 / 副歌3 1.0）
2. **贝斯** Bass + Sub 双层（Sub 低通 160Hz）
3. **钢琴** 前奏分解 / 主歌分解 / 副歌柱式
4. **弦乐垫** Pad 全曲持续，段落音量动态
5. **琶音** Pluck 副歌 16 分音符、间奏慢速
6. **主旋律** Lead 手工编写（主歌A/B + 副歌1/2/3 + 副歌3 升调 +2 半音）
7. **铃音** Bell 副歌3 点缀

## 混音母带链

混响（Schroeder）→ 延迟（Lead）→ 低通滤波（Bass/Sub）→ 立体声加宽（Haas 0.4）→ 软削波（1.5）→ 淡入淡出（0.8s/4.0s）→ 归一化（0.95）

**峰值 0.95 / RMS 0.376**，无削波、动态合理，可直接播放分享。
