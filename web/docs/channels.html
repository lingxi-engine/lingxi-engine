渠道接入

灵犀引擎支持 9 个社交渠道接入，让你在微信、Telegram、Discord 等平台直接使用引擎的 AI 能力。

支持的渠道

📱 微信

支持公众号和企业微信两种模式。

Webhook 地址：/api/channels/wechat/webhook

✈️ Telegram

通过 Bot API 长轮询接入。

💬 Discord

通过 Bot 接入，支持频道和私聊。

💼 Slack

支持 Bot + Socket Mode。

📞 WhatsApp

通过 Business API 接入。

🔒 Signal

通过 signal-cli 接入。

🍎 iMessage

仅 macOS，通过 AppleScript 接入。

🐦 QQ

通过官方 Bot API 接入。

📄 飞书

通过机器人接入。

Webhook 地址：/api/channels/feishu/webhook

配置渠道

通过 API 配置新渠道：

POST /api/channels
Content-Type: application/json

{
  "id": "wechat-main",
  "type": "wechat",
  "config": {
    "mode": "mp",
    "appId": "wx_your_app_id",
    "appSecret": "***",
    "token": "***"
  }
}

管理渠道

  • GET /api/channels — 列出所有渠道
  • POST /api/channels/:id/enable — 启用/禁用
  • DELETE /api/channels/:id — 删除
