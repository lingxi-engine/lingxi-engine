手机端使用

灵犀引擎支持 PWA（渐进式 Web 应用），安卓和 iOS 都可以用，无需下载安装包。前提是你已经安装了自己的引擎：装在本机，或部署在你自己的云服务器（见云端自主部署）。

安装步骤

1. 安卓手机

用 Chrome 或 Edge 浏览器打开你自己的灵犀引擎页面（本机安装后是 http://localhost:3456，自部署则是你的服务器地址），点击地址栏的「安装」或「+」→「添加到主屏幕」→ 桌面出现灵犀引擎图标。

2. iPhone

用 Safari 浏览器打开你自己的灵犀引擎页面（同上，本机或你自己的服务器地址），点击底部分享按钮 →「添加到主屏幕」→ 同样全屏运行。

功能说明

聊天

手机和电脑打开同一个引擎地址（本机或你自己的服务器），看到的就是同一份会话与数据，无需额外同步。

离线使用

首次打开后，Service Worker 会缓存页面资源，之后没网络也能看缓存内容。新对话需要联网。

群聊权限

在手机端聊天界面点击右上角「群聊设置」，可以设置自己的智能体是否允许别人使用：允许群内所有好友使用 / 指定好友可用 / 不让别人用。

其他接入方式

除了 PWA，还可以通过微信、Telegram、Discord 等渠道接入引擎，具体配置见渠道接入。
