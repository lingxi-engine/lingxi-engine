常见问题

Q: 灵犀引擎是免费的吗？

A: 是的，灵犀引擎完全免费开源。你可以自由使用、修改和分发。

Q: 我的数据会上传到云端吗？

A: 不会。灵犀引擎是本地优先设计，所有对话记录、配置和数据都存储在你自己的设备上。只有你主动发起的 API 请求会发送到你配置的模型服务商。

Q: 支持哪些大模型？

A: 支持 OpenAI、DeepSeek、Claude、Google Gemini 等主流服务商，也支持 Ollama 本地模型和任何兼容 OpenAI API 的自定义端点。

Q: 我需要编程基础吗？

A: 不需要。下载安装后，打开应用，添加你的 API Key，就可以直接开始对话。高级功能（Agent、工作流）可选学习。

Q: 手机上能用吗？

A: 可以。支持 PWA（安卓/iOS 浏览器添加到主屏幕）和微信/Telegram/Discord 等渠道接入。

Q: 怎么在群聊里让别人用我的智能体？

A: 在聊天界面点击「群聊设置」，选择「允许群内所有好友使用」或「指定好友可用」，勾选对应的好友即可。

Q: 遇到问题怎么寻求帮助？

A: 可以通过 Telegram、Discord 等渠道接入引擎，或者在 GitHub 上提交 Issue。

Q: 支持哪些操作系统？

A: 支持 Windows、macOS、Linux。手机通过 PWA 或渠道接入。
