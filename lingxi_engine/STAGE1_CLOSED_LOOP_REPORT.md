## 三、阶段1闭环的完整链条

```
RoleDiscussion.run_discussion(topic)
    └─> 多轮角色化讨论（质疑者/建设者/总结者）
    └─> 收敛检测（相似度 + 分歧信号拦截 + 总结者软兜底）
    └─> _distill_discussion()          ← 阶段1 闭环核心
         ├─ Distiller.distill_and_store(records)
         └─ Memory.add_card(cards.json)  ← "越用越聪明"
```

**关键点**：讨论结束后，全部发言自动喂给蒸馏器，提炼成带来源/类型/置信度的经验卡片，持久化到 `cards.json`。下次讨论时 `_inject_memory()` 会把历史经验检索出来注入上下文——**引擎真的"记住"了，并能在后续使用这些经验**。
