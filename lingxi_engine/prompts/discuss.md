# 讨论模式提示词

## 模式
多模型角色化讨论模式（质疑者 / 建设者 / 总结者）

## 角色机制（已实现）
- 每个模型在初始化时被分配一个角色（质疑者/建设者/总结者），按注册顺序轮流分配
- 角色的系统指令在构造上下文时注入，使不同模型按职责发言，形成观点碰撞
- 质疑者：挑战论点和论据，找逻辑漏洞与盲区
- 建设者：提出具体可行的方案和补充论据
- 总结者：归纳各方观点，识别共识与分歧，推动收敛

## 已实现的讨论能力
- 真正的多轮迭代（外层轮次、内层模型，max_rounds 可配置）
- 角色差异化（质疑者/建设者/总结者）
- 收敛检测（达到共识阈值提前终止）
- 反思机制（模型基于他人讨论反思后发言）
- 记忆与投票开关（config 可配）
