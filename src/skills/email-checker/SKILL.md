# 邮件检查技能

## 触发条件
- 用户说"检查邮件"/"查收件箱"/"有新邮件吗"
- Cron 定时触发（建议每 30 分钟一次）

## 执行步骤

1. **获取邮件列表**
   - 调用 `web_search` 搜索邮件服务商的未读邮件 API
   - 或使用 `scrape_url` 抓取网页版邮箱
   - 支持的邮箱：Gmail, Outlook, QQ邮箱, 163邮箱

2. **生成摘要**
   - 提取发件人、主题、时间
   - 按重要程度排序（含关键词的优先：紧急/重要/截止/会议）
   - 生成简洁摘要列表

3. **推送结果**
   - 写入收件箱（data/inbox/）
   - 如果有重要邮件，通过通知推送

## 输出格式

```
📬 邮件检查报告 (2026-06-23 14:00)

未读邮件 3 封：

🔴 [紧急] 张经理 - 项目截止提醒 (14:02)
   明天是提交截止日，请确认进度

🟡 王工 - 周报模板更新 (13:30)
   新模板已上传，请查收

⚪ 订阅 - 技术周刊 #142 (10:00)
   本周 AI 领域精选
```

## 配置
用户需要在设置中配置邮箱信息：
- 邮箱类型（Gmail/Outlook/QQ/163/自定义）
- IMAP 服务器地址（可选）
- 邮箱账号
- 应用专用密码（非登录密码）

## 注意事项
- 不存储邮件密码明文
- 只读模式，不发送/删除邮件
- 首次使用需用户授权
