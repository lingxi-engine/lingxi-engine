# 天气播报技能

## 触发条件
- 用户说"今天天气"/"明天会下雨吗"/"带伞吗"
- Cron 定时触发（建议每天 7:00 和 18:00）

## 执行步骤

1. **获取天气数据**
   - 调用 `scrape_url` 抓取 wttr.in 简洁天气页
   - URL 格式：`https://wttr.in/{城市}?format=3`（简洁）或 `https://wttr.in/{城市}`（完整）
   - 支持中文城市名：北京、上海、广州、深圳等

2. **解析天气信息**
   - 当前温度、体感温度
   - 天气状况（晴/多云/雨/雪）
   - 风向风力
   - 未来 3 天预报
   - 日出日落时间

3. **生成播报**
   - 日常模式：简洁一句话
   - 详细模式：完整预报
   - 出行建议：是否需要带伞/加衣

4. **推送结果**
   - 写入收件箱（data/inbox/）
   - 如果有恶劣天气预警，主动通知

## 输出格式

### 日常模式（Cron 早晨推送）
```
🌤️ 上海天气 · 6月23日 周一

26°C 多云 → 31°C 午后有雷阵雨
💨 东南风 3级 | 💧 湿度 72%
🌅 日出 05:42 | 🌇 日落 19:08

⚠️ 下午可能下雨，建议带伞
```

### 详细模式
```
🌦️ 上海未来 3 天天气预报

今天 6/23: 26-31°C ⛈️ 雷阵雨
明天 6/24: 24-28°C 🌧️ 中雨
后天 6/25: 23-27°C ☁️ 多云

📌 本周多雨，出门记得带伞
```

## 配置
用户需要在设置中配置：
- 城市（默认：上海）
- 推送时间（默认：7:00 和 18:00）
- 模式（简洁/详细）

## 数据源
- wttr.in（免费，无需 API Key）
- 也可以使用 `web_search` 搜索"城市名 天气"
