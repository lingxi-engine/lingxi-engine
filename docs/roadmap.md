# Public roadmap

This roadmap is intentionally conservative. Labels describe current confidence, not aspiration.

## Stable foundation

These areas best match the current public positioning:

- Self-hosted TypeScript app for chat, agents, auth, storage, and WebSocket-based interaction
- Local persistence and model-provider configuration via environment variables
- Python `lingxi_engine/` collaboration framework and its regression suite
- Contributor workflows around type checking, tests, and repository hygiene

## Beta

These areas exist and are useful, but need broader field validation or clearer operator guidance:

- Docker-backed sandbox execution
- Channel adapters and webhook-style integrations
- Mobile packaging/app-shell workflows
- Download/release packaging flows

## Experimental

These areas are promising but should not be marketed as broadly stable today:

- Mesh/networked multi-instance collaboration
- Marketplace, hiring, or platform-style workflows
- Public website/demo automation and global distribution flows
- Broader self-improvement or autonomous orchestration research tracks

## Near-term public beta priorities

1. Keep the repository English-first for external developers while preserving Chinese companion docs.
2. Tighten release/version/documentation consistency.
3. Separate maintainer-internal deployment assets from public-facing materials.
4. Improve external contributor onboarding and issue triage.
5. Expand evidence-backed deployment/security guidance before any public internet demo.
