☁️ 部署到你自己的云服务器

想手机、电脑随时随地访问？把灵犀引擎部署到你自己的云服务器（VPS）即可——引擎跑在你的服务器上，数据完全归你。官网不提供托管聊天服务，你的引擎只跑在你的机器上。

1

准备一台云服务器

任意厂商的 Linux 服务器均可（Ubuntu 20.04+ / Debian 11+ / CentOS Stream 8/9），建议 1 核 2GB 起步，无需 GPU。

2

一条命令安装

SSH 登录服务器后执行：

curl -fsSL https://www.lingxi-engine.com/install.sh | bash

自动安装 Node.js 与全部依赖，部署到 /opt 目录并由 PM2 托管、开机自启。

3

浏览器访问

打开 http://你的服务器IP:3456 即可使用，手机电脑访问的是同一个引擎。记得在安全组/防火墙放行 3456 端口；生产环境建议绑定域名并配置 HTTPS 反向代理。
