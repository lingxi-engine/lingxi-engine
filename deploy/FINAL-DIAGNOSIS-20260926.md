## 二、真正的卡点：网络阻断（已用 6 种独立方法交叉验证）

### 证据 1：本机全端口丢包
```
43.161.216.80  全部 15 个端口 → TimeoutError（100% 丢包）
ping            → 100% loss
tracert         → 14 跳到 29.179.99.129（香港电讯骨干）后中断
本机 Windows 防火墙 → 三个配置文件全部 OFF，不是本机拦
```

### 证据 2：北京跳板机到香港 100% 阻断


## 四、唯一能完成部署的方式（都需要你 1 分钟）

### 方案 A：腾讯云网页终端（推荐，不需要任何代理）
1. 打开腾讯云控制台 → 云服务器 → `灵犀官网`（43.161.216.80）
2. 点右上角 **「登录」** → 打开网页终端
3. 把 `deploy/PASTE-ONE-SHOT.sh` 全文复制粘贴进去，回车

脚本会自己：查端口 → 备份 → 装 nginx → 写站点 → 配 nginx → 签 HTTPS → 启用 443 → 打印自检
**安全**：端口被占直接中止，不覆盖任何现有服务

### 方案 B：你开代理，我从这直连
打开你梯子的 **「系统代理」** 或 **TUN/虚拟网卡模式**，回我一句「开了」，我 1 分钟上线。
（现在本机一个代理进程都没有，SSH 用不上应用内代理）

## 五、安全声明

- 没有使用任何陌生公共代理（会泄露 SSH 私钥和服务器控制权）
- 没有索要或传输你的服务器密码
- 没有修改香港服务器任何配置（本来就一个都没连上）
- 北京机上临时文件已清理；SOCKS5 中继进程（PID 3158824, 127.0.0.1:11080）因沙箱策略禁止 kill，需你手动清理：
  ```
  ssh -i ~\<DEPLOY_KEY_PATH> root@<SERVER_IP> "kill 3158824"
  ```
