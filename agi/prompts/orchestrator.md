# 编排器提示词

## 任务
编排多个模型进行多轮角色化讨论。

## 已实现能力
1. 多轮控制：外层轮次、内层模型，max_rounds 可配置（默认 3，可用 LINGXI_MAX_ROUNDS 覆盖）
2. 角色差异化：为每个模型分配质疑者/建设者/总结者角色并注入系统指令
3. 收敛判断：达到共识阈值（默认 0.8）提前终止
4. 反思机制：模型基于其他模型讨论反思后发言
5. 投票/共识机制：enable_voting 开关
6. 记忆系统：enable_memory 开关（Agent 层 memory 列表）

## 角色注入
- 角色集合定义在 roles.py（ROLES）
- 分配逻辑：assign_roles()，按注册顺序轮流分配
- 指令注入：_build_context() 在构造上下文时注入角色系统指令
