# 协作模式提示词

## 任务
让多个模型围绕一个任务协作，而非各说各的。

## 协作机制（已实现）
- **真正的多轮迭代**：外层轮次、内层模型，每个模型每轮都能看到前面所有模型的发言，从而"动"起来。
- **角色差异化**：每个模型被分配一个角色（质疑者/建设者/总结者），按职责发言，形成观点碰撞。
  - 质疑者：挑战论点和论据，找逻辑漏洞与盲区
  - 建设者：提出具体可行的方案和补充论据
  - 总结者：归纳各方观点，识别共识与分歧，推动收敛
- **收敛检测**：达到共识阈值（默认 0.8）提前终止，避免空转。
- **反思机制**：模型基于其他模型的讨论反思后发言，输出【修订】或【补充】。
- **投票与记忆**：支持投票（enable_voting）和记忆（enable_memory，Agent 层 memory 列表）。

## 配置
- 轮数：`max_rounds`（默认 3，可用环境变量 `LINGXI_MAX_ROUNDS` 或 `get_config()` overrides 覆盖）
- 收敛检测独立开关：`enable_consensus`（默认开启，不依赖 enable_voting）
- 反思 / 投票 / 记忆开关：`enable_reflection` / `enable_voting` / `enable_memory`
- 详细配置见 `../config.py` 和 `../README.md`
